# VK Бот с Автоворонкой

Бот для **ВКонтакте**, который:
1. Выдаёт видео в обмен на **email/телефон** (сохраняет в **Bitrix24**).
2. Предлагает записаться на **15-минутную сессию** через **Calendly**.
3. Логирует все действия.
